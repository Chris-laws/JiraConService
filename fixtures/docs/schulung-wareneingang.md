Schulungsunterlage für Filialteams, Modul Wareneingang.

Eine Teillieferung liegt vor, wenn weniger Paletten ankommen als im Lieferavis angekündigt. Erfasse zuerst die
gelieferten Paletten, dann markiere die fehlenden Positionen als offen. Seit Release 2026.10.2 prüft das System
Teillieferungen beim Abschluss. Bricht der Wareneingang ab, melde die Störung mit Lieferscheinnummer über
ServiceNow.
